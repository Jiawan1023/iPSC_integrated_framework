Figure_code folder contains scripts to generate plots for the figures in the paper.
1. generate_heatmap.R for Figure1(c), Figure4(f-g), Figure6(e), Suppfig3(c), Suppfig5(d).
2. generate_dotplot.R for Figure 2(b,d), Figure 3(g), Suppfig 3(a-b,d), Suppfig 4(a-e), Suppfig 7(b) and Suppfig 9(d)
4. barplot.R for Figure 3, Figure 4, Figure 6, Suppfig 6, Suppfig 8, Suppfig 9 and Suppfig 11.
5. volcanoplot.R for Suppfig 1(d), Suppfig 2(a), Suppfig 5(c) and Suppfig 8(b).
7. upsetplot.R for Figure 4(b).
8. densityplot. R for Figure 5(a) and Suppfig 10(a).
9. lineplot.py for Suppfig 2(c).
10. violinplot.R for Figure 3, Suppfig 5, Suppfig 6.
